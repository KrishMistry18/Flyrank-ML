I built a machine-learning workflow to identify and prioritize decaying content by generating a ranked review queue for editorial teams. I evaluated this RandomForest model using an anonymized 30,000-page sample of FlyRank's production search dataset, enforcing strict client-grouped validation to prevent target leakage. The final defensible model achieved 51.00% Precision@100 and demonstrated that observable pre-decline signals can meaningfully prioritize human intervention without relying on harmful automated publishing.
